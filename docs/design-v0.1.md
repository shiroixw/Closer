# Closer — v0.1 设计

状态：**已定稿，待实现**。所有曾有的分歧都已收敛，结论见 `docs/decisions.md`。

先读 `CONSTITUTION.md`。那份文件说**为什么**、以及**什么时候该停**；这份文件说**怎么做**。

---

## 1. 范围

只做一件事，并把它做对：点击一张值得看的图，就地按原尺寸打开。

**做**：拦截 → 判断 → 让位检测 → overlay（缩放 / 平移 / 旋转 / 翻转 / 适应）→ 信息面板（尺寸、比例、百万像素、格式、大小）→ 复制 / 保存 → 按站点暂停。

**不做**：见宪法「非目标」。尤其是背景图、`canvas`、图集漫游、批量保存，以及任何超出暂停列表的设置页。

---

## 2. 权限模型

**默认开启，全站生效；由用户按站点关闭。** 是 opt-out，不是 opt-in。

安装时**不申请**任何 host 权限。`*://*/*` 声明为*可选* host 权限，让安装过程干净，并在有上下文的时刻、带着理由，只问一次。

```
install
  └─ 打开 welcome 页
       ├─ [Enable Closer]  → chrome.permissions.request({ origins: ['*://*/*'] })
       │     └─ 授权成功 → background 注册 content script
       │                 → background 向当前活动标签页补注入（已打开的页面）
       └─ [Not now]        → 扩展保持静默；popup 继续提供授权入口
```

**注册是动态的。** `chrome.scripting.registerContentScripts`，`runAt: 'document_start'`、`allFrames: false`。不能用静态 `content_scripts`，因为 host 权限是可选的。`allFrames: false` 是刻意的：在 300px 宽的 iframe 里渲染出来的 overlay 会被裁掉，而被裁掉的「全尺寸查看」比没有更糟。

**暂停匹配。** 存储时去掉 `www.` 前缀；一条记录匹配它自己及所有子域（`example.com` 覆盖 `img.example.com`）。不引 PSL。

## 3. 点击契约

三段式。核心思想：**我们不抢，我们排队。** 页面先动手，页面没动手，才轮到我们。

### 3.1 候选过滤（同步，< 1 ms）

只有它**确实是一次点击**、且目标**确实是一张值得看的图**，才进入下一段。

| 条件 | 规则 |
| --- | --- |
| 按下到抬起期间指针位移 > 6 px | 不是点击，直接放行 |
| 按住超过 600 ms | 不是点击，直接放行 |
| 按下时有文字被选中 | 放行 |
| 按住 `⌘ / Ctrl / Shift / Alt` | 放行（用户要的是新标签页 / 保存 / 等） |
| 中键或右键 | 放行 |
| overlay 已经打开 | 点击归 overlay 所有 |
| 偏好尚未加载完成 | 放行（杜绝竞态，窗口约 5 ms） |
| `judge()` 否决 | 放行 |

监听挂在 **window 捕获阶段**：`pointerdown` 记录，`click` 决策。在这一段**不做任何阻止**——不是候选就什么都不做，页面拿到完整的一次点击。

### 3.2 让位检测（异步，下一帧）

是候选时，只做一件事：`preventDefault()`，阻止裸图跳转。**不调用** `stopImmediatePropagation()`，页面的处理器照常跑完。

在 `click` 那一刻先记一份基线，下一帧比对五项：

| 判据 | 说明 |
| --- | --- |
| `location.href` | 变了（含 SPA 的 `pushState`） |
| **目标的属性** | 被点的这张图、或离它五层以内的容器，`style` / `class` 被改写（站点把放大写在同一个 `<img>` 或它的盒子上） |
| `document.fullscreenElement` | 变了 |
| 滚动锁 | `documentElement` / `body` 的 `overflow` 从可滚变成 `hidden` |
| **命中点** | `elementFromPoint(x, y)` 不再是基线里那个元素 |

命中点一项是关键：**必须比「和基线是不是同一个元素」，不能比「是不是那张图」**。卡片式布局里，图片上方常常盖着一层链接或遮罩，按「是不是图」判会永远误判成「页面动过了」，产品直接废掉。

「目标的属性」管的是这样一种站点（2026-10-20 的 Pexels 照片页）：点图不导航、不弹层，而是把 `transform: scale(3)` 写回那张图本身，做成一个跟随鼠标的放大镜。元素身份、位置、滚动、`href` 全不变，**另外四个判据一个都不响**。所以这里比的是**属性**，不是几何：`hover` 缩放走样式表、不写属性，几何判据会把这类站点整片误伤。

范围是图自己加上离它五层以内的容器：同一个放大镜只要换个写法——class 加在包着图的盒子上、CSS 去缩里面的图——图自己的属性就一个字都不变，一样会漏。到 `body` 为止：它和 `html` 上的 class 常年被菜单、主题、弹窗改写，那不是这次点击的证据。

基线比对时，落在 Closer 自己 overlay 里的命中点视为「未变化」，否则我们一打开就会把自己判成入侵者。

五项任一成立 → 我们退场，什么都不做。全不成立 → 打开。

### 3.3 迟到纠正

有些站点的查看器要等图片取回来才挂载。因此打开后再补两次检查（600 ms、1200 ms）：若此时命中点被页面盖住，**我们自己关掉**。会闪一下，但比两张查看器叠着强。

## 4. 判断器

只有一个函数。按顺序执行，第一条否决即返回。模糊即否。

| # | 信号 | 结果 |
| --- | --- | --- |
| 1 | `naturalWidth` 或 `naturalHeight` 为 0（尚未解码） | 跳过 |
| 2 | 渲染尺寸 < 40 × 40 px（图标、头像、sprite） | 跳过 |
| 3 | 原始面积 < 40 000 px²（约 200 × 200） | 跳过 |
| 4 | 原始短边 < 48 px（横幅、分割线、长条） | 跳过 |
| 5 | 位于 `[data-closer-ignore]` 之内 | 跳过 |
| 6 | 位于 `button, [role=button], label, select, input, textarea, summary, option, [contenteditable]` 之内 | 跳过 |
| 7 | 位于 `header, nav` 之内**且**渲染高度 < 80 px（logo） | 跳过 |
| 8 | 位于 `<a download>` 之内 | 跳过 |
| 9 | 位于 `<a>` 之内，且 href 既不是图片也不是裸 `#` | 跳过 |
| 10 | 祖先链里有 `[data-lightbox]`、`[data-fancybox]`、`[data-fslightbox]`、`[data-featherlight]`、`[data-zoom]`、`a[rel~="lightbox"]`，或已打开的 `<dialog>` / `[role="dialog"][aria-modal="true"]` | 跳过 |
| 11 | 原始尺寸是正方形且短边 < 600 px（二维码、头像） | 跳过 |
| 12 | 祖先链上有一块自己声明了 `cursor: pointer` 的区域（认「声明的边界」：父元素不再是 pointer 的那个元素） | 跳过 |
| 13 | 其余情况 | **打开** |

第 3 条的门槛在 2026-10-20 的实测里从 10 000 px² 上调到 40 000 px²：阮一峰周刊结尾那张 150×150 的公众号二维码（22 500 px²）当时会被判成候选，点开会是一张被放大到糊的二维码。代价是 250×150 这类小图表也会被跳过——按第二条，这个代价可以接受。

**判断器不认识「看图器」这个概念。** 第 10 条只覆盖按库约定写的图集——它明确声明了所有权，零成本让开。至于手写的查看器、点了什么都不做的正文图、点了跳详情页的卡片，一律交给第 3 节的让位检测去分辨。所以这里没有 `cursor: zoom-in` 这条规则：它既可能意味着「站点能放大」，也可能只是「这张图能点」，方向不明，而行为已经能回答，不需要它。

**但行为回答不了其中一种。** 2026-10-20 的实测：一个 H5 活动页把整张卡片做成 `<section>` + JS 事件委托，既不是 `<a>` 也不是 `<button>`，点击后只改自己某个元素的文字/class——`href`、`fullscreen`、命中点、滚动锁四个判据全部沉默，于是被我们接管（用户报的 bad case）。所以第 11 条保留 `cursor: pointer`：它与 `zoom-in` 不同，没有方向歧义，只表示「点我」。`cursor` 是继承属性，因此只认「声明的边界」（父元素不再是 pointer 的那个），否则 `body{cursor:pointer}` 的页面会整站失效。代价写在 D24。

判断器所需的一切都来自该元素及其祖先链。不读正文、不读表单状态、不读历史。

## 5. Overlay

### 5.1 机制

Shadow DOM host，挂在 `document.documentElement` 上，`position: fixed`、`inset: 0`、`z-index: 2147483647`，`:host { all: initial }`，样式表通过 `adoptedStyleSheets` 注入，页面 CSP 拦不住。

不用 iframe：开启动画需要源元素的 `getBoundingClientRect()`，好让图从它自己的缩略图里飞出来。

不用 Popover API：UA 样式表对关闭态的 `display: none` 会和 `:host { display: block }` 打架，收益也不比一个打满的 z-index 大多少。等真有页面翻车再说。

### 5.2 结构

```
ⓘ                                            ⧉   ⤓   ✕
                    ┌──────────┐
                    │  image   │
                    └──────────┘
```

- 左上角：**ⓘ**（圆圈内一个感叹号），32 px 命中区。点击展开信息面板。
- 右上角：**复制**、**保存**、**关闭**。18 px 线性图标，`currentColor`，1.5 px 描边。
- 底部：**什么都不放。** 上一版的尺寸 HUD 已并入信息面板。
- 所有 chrome 在 2.2 s 无操作后淡出，指针一动就回来。鼠标停在某个按钮上时不淡出。

文字一律短：只有数字、格式代号和站名，没有标签、没有句子。

### 5.3 信息面板

从 ⓘ 下方展开，宽 232 px，深色半透明卡片，圆角 12 px。内容按重要性排，不加标题：

```
1920 × 1080          ← 15 px / 500
shown 640 × 360      ← 只在页面缩放显示时出现，12 px 弱化
3:2 · 2.07 MP        ← 12 px
JPEG · 412 KB        ← 12 px
────────────────
Pause on example.com ← 12 px，悬停变亮
```

- `ⓘ` 或 `I` 切换；点面板外关闭；`Esc` 先收面板，再按一次才关 overlay。
- 比例用最大公约数算（≤ 21 的整数比），算不出好看的就退回两位小数。
- 文件大小取不到时，整行不显示——不写「未知」。

### 5.4 复制

**复制的是图片本身**（PNG，可直接粘进文档或聊天框）；按住 `⇧` 点击则复制**图片地址**（纯文本，永不失败）。按钮的 tooltip 写明这一点。

路径：SW 取回字节 → `Blob` → `objectURL` → `<img>` → `canvas` → `toBlob('image/png')` → `ClipboardItem`。`objectURL` 是同源的，所以跨域图片也能画进 canvas，不会被污染。

成功后图标变对勾 1.2 s；失败在底部出一行 `Copy failed`，1.4 s 后消失。动图会变成静态 PNG——可接受，需要动画请用保存。

### 5.5 保存

取回字节 → `Blob` → `objectURL` → `<a download>` → 点击 → 释放。**不申请 `downloads` 权限**，也不改浏览器下载行为。

文件名取 URL 末段；没有图片扩展名时用 `image-<宽>x<高>.<扩展名>`。保存的是原始字节，动图仍是动图。

### 5.6 缩放与平移

`fit = min(94% vw / nw, 94% vh / nh)`，上限 4×（免得一张 96 px 的图糊成一片）。缩放区间 `fit × 0.4` … `fit × 8`。

- 滚轮：以指针为锚点，`exp(-deltaY × 0.0018)`；触控板双指捏合（`ctrl + wheel`）走同一条路径
- 键盘：以中心为锚点
- 拖拽：按屏幕像素平移
- 双击：在「适应」与「100%」之间切换

两处实测出来的真相，都不改设计，但要知道：

- **`fit` 可能比页面画得更小。** 实测那张 800 × 1000 的图，页面按 809 × 1009 画，`fit` 在 1513 × 936 的视口里算出来是 0.88，也就是 704 × 880——比页面还小。对这类「页面上已经接近 1:1」的图，overlay 的价值不是变大，是纯色背景、滚轮放大、信息面板和复制保存。这是「适应屏幕」的必然代价，不修。
- **`1` 在 Retina 上是插值放大。** dpr = 2 时，`s = 1` 意味着一个图像像素铺满两个物理像素，最锐的其实是 `s = 0.5`。保持 `1` = 1 图像像素 / 1 CSS 像素这个通行约定，不改成物理像素——否则「100%」会让图变小，比模糊更难解释。

### 5.7 键位

| 按键 | 动作 |
| --- | --- |
| `Esc` | 收面板 → 关闭 |
| `I` | 信息面板 |
| `0` | 适应屏幕 |
| `1` | 100%（1 图像像素 = 1 CSS 像素） |
| `+` `-` | 缩放 ×1.25 / ×0.8 |
| `R` | 旋转 90° |
| `F` | 水平翻转 |
| `B` | 循环背景（深 → 浅 → 棋盘，记忆） |
| `Enter` | 走这次点击原本该走的链接 |

按键在 window 捕获阶段吃掉，overlay 打开期间页面自己的方向键和 `Esc` 处理器看不到它们。

### 5.8 动效

开启是一次 FLIP：从缩略图的矩形起步（`s = rect.width / naturalWidth`，相对视口中心偏移），动画到适应屏幕。260 ms，`cubic-bezier(.22,.72,.18,1)`。关闭反向回到源图**当前**的矩形；源图已移除或滚出视野则淡出。

`prefers-reduced-motion` → 时长 0，无例外。

## 6. 架构

无构建步骤。不打包、不转译、零依赖。文件按 manifest 顺序加载进同一个 isolated world，共享一个 `window.Closer` 命名空间。

```
manifest.json
_locales/
  en/ zh_CN/           两种语言的文案（D28）
src/
  background.js        注册、权限同步、字节取回
  content/
    core.js            命名空间、文案（Closer.t）、偏好缓存、暂停列表
    detect.js          judge()
    yield.js           让位检测与迟到纠正
    meta.js            尺寸、比例、格式
    bytes.js           取字节（一次打开一份，按 url 缓存一条）
    overlay.js         shadow DOM 视图、动效、键位
    actions.js         复制、保存
    boot.js            指针/点击捕获与接线
  ui/
    popup.html/.js     按站点暂停、授权
    welcome.html/.js   首次运行、暂停列表
    i18n.js            扩展页面的文案入口（content 侧不用它）
    ui.css
icons/
tools/icons.py         图标渲染器（PNG 的来源）
```

**为什么只有 service worker 能读字节。** 页面能报原始尺寸，但报不出文件大小：跨域响应没有 `Timing-Allow-Origin` 时，`PerformanceResourceTiming.encodedBodySize` 会被清零。content script 也读不到字节——它继承页面的 CORS 规则。只有扩展上下文可以。于是 SW 取回并返回，复制和保存都复用它。

- 只量大小：流式读取并计数，不缓冲（`reader.read()` 循环累加）
- 需要字节（复制 / 保存）：`arrayBuffer()` 一次性返回

**文件大小的兜底顺序**：`performance` 条目 → SW 探测 → 显示为缺失。签名 URL 返回 500 或 `401` 不是错误，只是一个缺失的数字。

## 8. 已知失败模式

| 场景 | 行为 | 备注 |
| --- | --- | --- |
| 站点自带查看器 | 它开，我们退场 | 让位检测的正面用例 |
| 站点用 `target=_blank` / `window.open` 开新窗口 | 会双开，在两个地方 | 判据看不到新窗口，已知，罕见 |
| 点击只改自身状态（文字、class、tab 高亮），不跳转不弹层 | 四判据全哑；容器声明了 `cursor:pointer` 时由第 11 条兜住，否则我们接管 | `docs/cases.md` 001 / 002 |
| 就地放大的读图器（点图把 `transform` 写回那张图或它的盒子，随鼠标平移） | 目标属性变了，我们退场，站点的放大镜保留 | Pexels 照片页；cases 004 |
| 放大写在 `body` / `html` 上，或点击 600 ms 之后才写 | 我们接管（迟到纠正只看命中点） | 同族盲区；`e6` 的 Z/W 都盖不到 |
| 只改 `src` / `srcset` / `data-*`，不碰 `style` / `class` | 我们接管 | 与懒加载的换图、换状态属性无法区分，故意不收 |
| 放大只走 `element.animate()` 或内部 JS 状态，不写任何属性 | 我们接管 | 隔离世界观测不到；同族盲区 |
| JS 事件委托的可点卡片，容器**没有**声明 `cursor:pointer` | 我们接管 | 静态无解（`addEventListener` 不产生属性），cases 002 已接受 |
| 页面在 600 ms 之后才挂载查看器 | 我们先开，随后自己关掉 | 会闪一下 |
| 缩略图被商品链接包着 | 跳过 | 第 9 条 |
| 懒加载图，从未解码 | 静默跳过 | 第 1 条 |
| 图嵌在 iframe 里 | 不捕获 | `allFrames: false`，接受 |
| 签名 URL 拒绝探测 | 显示尺寸，省略文件大小 | 优雅降级 |
| 签名 URL 拒绝取字节 | 复制与保存报 `Copy failed` | 不静默失败 |
| 页面 `<html>` 带 `transform` | overlay 位置偏移 | 已知；解法是 top layer |
| 页面处于元素全屏 | overlay 被压在后面 | 已知，罕见 |
| 复制动图 | 得到静态 PNG | canvas 转换的固有损失，保存可保原样 |
| `chrome://`、应用商店、PDF 阅读器 | 不注入 | Chrome 限制 |

## 9. v0.1 的完成定义

逐条手工跑，每条只有通过与失败两种结果。

1. 新闻文章页：点主图打开；点 logo、作者头像、社交图标毫无反应。
2. 电商列表页：点商品图**不劫持链接**。
3. 自带查看器的站点：点图是**它的**查看器打开，我们全程没有出现。
4. 正文图点了没反应的站点：我们的 overlay 打开，延迟无感。
5. 在图上拖选文字，不打开任何东西。
6. `⌘` + 点击通过的图，开新标签页，不开 overlay。
7. `Esc` 关闭后，滚动位置、DOM、焦点均未改变。
8. `ⓘ` 展开后能看到原始尺寸与页面实际显示尺寸；跨域图片能报出文件大小。
9. 复制能粘进聊天框；`⇧` + 复制得到 URL。
10. 保存得到的文件名与原始一致，动图仍是动图。
11. 「Pause on …」之后，同站点下一次点击立刻恢复原生行为，无需刷新。
12. 已发布的 JS 总量 < 60 KB（未压缩）。原为 40 KB，宪法第六条 D21 修正后放宽，见 `docs/decisions.md`。

## 10. 延后项及理由

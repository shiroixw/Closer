The judge判断器

The viewer is the easy half. Knowing which image you meant is the product. 看图器是容易的那一半。知道你点的是哪一张，才是产品本身。

Your browser already has an image viewer. So do a dozen extensions. What none of them has is judgment: on a page Closer has never seen, facing forty images, deciding which one you pointed at — and staying quiet when the answer isn't clear. 浏览器自带一个看图器，十几个扩展各有一个。它们缺的是判断力：在一个从没见过的页面上，面对四十张图，判断你点的是哪一张——拿不准的时候，就别出声。

Opens会打开

  • Photos drawn smaller than they really are被缩小显示的照片 a 1600 × 1000 photo shown at 980 × 613 in an article文章里一张 1600 × 1000 的图被画成 980 × 613
  • Screenshots squeezed into a column被压进一栏的截图 docs, issues, changelogs, forum posts文档、issue、更新日志、论坛帖子
  • Images that link to themselves链接指向图片本身的图 better than a bare jump to the file比直接跳到图片文件更好

Leaves alone不会碰

  • Icons, logos, banners, dividers图标、logo、横幅、分割线 too small to gain anything from opening太小，打开也看不到更多
  • Avatars and QR codes头像和二维码 you want to scan it or see the person, not the file你想扫它、或看这个人，不是看这张图
  • Images inside links, buttons and clickable cards链接、按钮、可点卡片里的图 the click belongs to them这次点击属于它们
  • Background layers behind the content垫在内容后面的背景层 full-width headers, hero backdrops通栏页头、首屏背景
  • Anything the site opens with its own viewer站点自己会用查看器打开的图 if the page reacts to the click, Closer steps aside — no double viewers页面对这次点击有反应，Closer 就退场——不会叠出两层
When in doubt, it doesn't open. Missing an image costs you one right-click. Hijacking a click costs you the page you were on — and that is how extensions get uninstalled. 拿不准，就不开。漏开一张图，代价是一次右键；误接管一次点击，代价是你正在看的那个页面——扩展就是这样被卸载的。

Privacy隐私

No tracking — by construction, not by promise. 不追踪你——靠构造，不靠声明。

Closer asks for the biggest permission an extension can: to run on every site you visit. The source code is the receipt. It ships exactly as written — no bundler, no minifier, nothing generated. Closer 索要的是一个扩展能提出的最大请求：在你访问的每个网站上运行。源码就是收据——它原样发布，不打包、不压缩、没有任何生成出来的代码。

Nothing leaves your machine什么都不离开你的电脑

No analytics, no telemetry, no crash reports, no remote config, no account, no server of its own.无统计、无遥测、无崩溃上报、无远程配置、无账号，也没有自己的服务器。

Exactly one kind of request只有一种网络请求

The bytes of the image you're looking at, to report its real file size. Measured in memory, then dropped. Already cached? Zero requests.取回你正在看的那张图的字节，用来报告真实文件大小。在内存里量完即丢。浏览器已缓存时，零请求。

Doesn't read the page不读页面

Only the image you clicked and its ancestors. Not the text, not your forms, not your history, not your cookies.只看被点的那张图和它的祖先链。不读正文、表单、浏览历史，也不读 Cookie。

Off until you say so你点头之前，它什么都不做

Site access is optional and requested from a button you press. Revoke it any time, from the welcome page, the popup, or chrome://extensions.站点访问是可选权限，只在你按下按钮时申请。随时可在欢迎页、popup 或 chrome://extensions 里撤销。

Install安装

Four steps, under a minute. 四步，不到一分钟。

There's no build step, so the repository is the extension. When the Chrome Web Store listing goes live, it will be a single click. 没有构建步骤，仓库本身就是扩展。等 Chrome 应用商店上架后，就只剩一次点击。

  1. Get the source拿到源码 Download the ZIP and unzip it, or git clone the repository. 下载 ZIP 并解压，或者 git clone 仓库。
  2. Open extensions打开扩展页 Go to chrome://extensions and turn on Developer mode, top right. 地址栏输入 chrome://extensions，打开右上角的「开发者模式」。
  3. Load it加载 Click Load unpacked and pick the folder that contains manifest.json. 点「加载已解压的扩展程序」，选中包含 manifest.json 的那个文件夹。
  4. Allow it授权 A welcome page opens. Press Allow on all sites. That's the only question it will ever ask. 会自动打开欢迎页，按「在所有站点上允许」。这是它唯一会问你的问题。

Chrome 110 or later. Also works in Chromium-based browsers that load Chrome extensions.需要 Chrome 110 或更高版本；能加载 Chrome 扩展的 Chromium 系浏览器同样可用。

For site authors写给网站作者

Add data-closer-ignore to an image or any of its containers and Closer will never touch it.给图片或它的任一容器加上 data-closer-ignore，Closer 就永远不会碰它。

Lightbox conventions are already respected: data-lightbox, data-fancybox, data-fslightbox, data-featherlight, data-zoom, rel="lightbox".常见灯箱库的约定已自动让路：data-lightbox、data-fancybox、data-fslightbox、data-featherlight、data-zoom、rel="lightbox"。

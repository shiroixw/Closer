# 决策记录

一条记录对应一个「做出它有代价」的决定。已锁定的结论要靠新增一条记录才能推翻——写在评论里的意见推翻不了决策。

---

## 已锁定

| # | 决策 | 理由 | 它封死了什么 |
| --- | --- | --- | --- |
| D1 | **黑名单权限模型。** 全站默认开，按站点关。 | 这个产品只有「不需要被请求就能工作」才存在。按站点 opt-in 是另一个产品。 | 白名单模式、任何企业式许可清单。 |
| D2 | **只做 `<img>`。** 不做背景图、`canvas`、`SVG` 文档。 | 其余场景的检测都是猜，而第二条说猜就是否。 | 「看看那张背景大图」的诉求。 |
| D3 | **定位是精准，不是功能。** 精准 / 简洁 / 快速 / 优雅。 | 和参考品比功能是一条必输且无边界的路。 | 功能对标式宣传、以「比 X 多」为卖点。 |
| D4 | **无构建步骤。** 平铺的 ES2022，按 manifest 顺序加载，共享 `window.Closer`。 | 第五条。可读源码是「全站权限」这张账单的收据。 | TypeScript、JSX、content script 里用 ES module。 |
| D5 | **Shadow DOM，不用 iframe。** | 开启动画需要源元素的矩形。 | iframe 级样式隔离与 `allow` 策略。 |
| D6 | **可选 host 权限，从 welcome 页授权。** | 在有上下文时询问，随时可撤销。 | 一次弹窗装完；一部分用户永不授权。 |
| D7 | **只有 service worker 可以取字节。** | 跨域下页面读不到字节；SW 是唯一有此特权的上下文。 | 纯页面侧的扩展。 |
| D8 | **只有英文，含 UI。**（**2026-10-20 被 D29 取代**） | 没有译者、没有框架，省掉参考品约五分之一的体积。 | 在出现志愿者之前的非英文市场。 |
| D9 | **被动让位模型。** 点击只 `preventDefault()`，不阻断传播；下一帧验「页面动过了没有」，动过就退场。 | 把「识别站点有没有看图器"这个不可能的问题，换成「这次点击有没有被别人消费」这个 O(1) 问题。也是第三条更强的实现。 | 「永远抢先」；双开风险从零变成需靠迟到纠正兜底。 |
| D10 | **判断器不认识「看图器」。** 删除 `cursor: zoom-in` 规则，只保留库约定属性作为零成本让路。 | `zoom-in` 方向不明（既可能是「能放大」也可能只是「能点」），而行为检测已经能回答，不需要它。删规则优于加规则。 | 靠静态先验覆盖手写查看器的所有尝试。 |
| D11 | **状态存 `local`，不碰 `sync`。** | 暂停了哪些站点不值得跨设备同步；宪法「非目标」写着不做云同步。 | 跨设备同步偏好；sync 的写入限流问题。 |
| D12 | **复制与保存复用 SW 的字节，不申请 `downloads`。** `<a download>` + `Blob` 足够。 | 少一个权限就等于少一段要解释的话。 | 更「原生」的下载文件名与目录控制。 |
| D13 | **底部 HUD 取消，信息收进左上角 ⓘ 面板。** | 主视图上只留图；尺子在你需要的时候出现。 | 常驻的尺寸显示；「一眼看到大小」的便利。 |
| D14 | **暂停入口在信息面板里，不进主 chrome。** | 逃生舱不该和常用动作平级，否则会被当捷径用。 | 一键暂停；缩略图级的暂停粒度。 |
| D15 | **iframe 内的图不处理**（`allFrames: false`）。 | 在 300px 的 iframe 里渲染的 overlay 会被裁掉，被裁掉的全尺寸查看比没有更糟。 | 嵌入型站点的覆盖。 |
| D16 | **暂停粒度到 host**（去 `www.`，覆盖子域），不到路径。 | 路径级暂停是给极少数站点的例外做设计，收益配不上这个设置面。 | 同一站点分区域开关。 |
| D17 | **MIT 许可。** 可商用、可改动，保留版权声明即可。 | 读者零成本判断自己能不能用；代码本身不构成护城河，清单和口碑才是。MIT 不授权商标，「Closer」这个名字仍归作者。 | 阻止闭源分支；要求衍生作品回馈。 |
| D18 | **原始面积门槛 10 000 → 40 000 px²。** | 实测：150 × 150 的二维码（22 500 px²）会被判成候选，点开是一张糊掉的二维码。40 000 约等于 200 × 200。 | 250 × 150 这类小图表也会被跳过。按第二条，可接受。 |
| D19 | **字节走 base64，不走 ArrayBuffer；打开时只量大小，复制/保存时才取内容。** | `runtime.sendMessage` 走 JSON 序列化，`ArrayBuffer` 到对面会变成 `{}`。而打开时就传整份内容，等于每次点击都付 1.33 倍图片体积的传输成本，违反 100 ms 首帧预算。 | 复制多等 100–300 ms（缓存通常已命中）；base64 让 64 MB 的上限更早触发。 |
| D20 | **迟到纠正用 `elementsFromPoint`，剪掉自己后取第一个。** | overlay 自己是 fixed + 最高 z-index，`elementFromPoint` 打开后永远返回我们自己，用它判「页面动过」结果恒为否——机制静默失效，且外观上只是双开。`acted()` 仍用单数版：它在打开前调用，host 还不存在。 | 每次检查多返回一整个视线列表，只在 600/1200 ms 各一次，可忽略。 |
| D21 | **体积预算 40 → 60 KB（宪法第六条修正）。** | 37.7 KB 只剩 2.3 KB，逼着人要么删注释（违反第五条）要么砍掉用户明确要的功能。注释占 6.95 KB（18%），删掉换来的余量是假的：代码一行没少，只是收据被撕了。 | 触发「必须砍功能」的时点后移 20 KB，功能膨胀更容易发生。这条不免费。 |
| D22 | **桩测试开头自动清理 Closer 扩展。** | 桩页面在 `127.0.0.1`，落在 `*://*/*` 内。任何残留实例都会抢走点击，而让位检测会让桩脚本**正确地**退让，于是断言报「overlay 没打开」——查这个假象烧了两轮。 | 每个桩测试多花 1.2 s（要等 chrome://extensions 渲染）。 |
| D23 | **「恢复」的口径按入口分：popup 删覆盖记录，welcome 删列表项。** | popup 面对的是「当前这个站点」，而挡住它的可能就是父域那一条（`sub.example.com` 被 `example.com` 暂停），只删精确项等于点了没反应；welcome 面对的是列表本身，每一行就是一条记录，删别的行是越权。两处行为不同，但都在回答各自界面上提出的那个问题。 | 在 `sub.example.com` 上点 Resume 会连带恢复同父域的其他子域——这比「点了没反应」好，但仍是一次隐式的宽恢复。 |
| D24 | **判断器第 11 条：祖先链上声明了 `cursor:pointer` 的可点区域，一律跳过。** | 2026-10-20 的 bad case：H5 活动页把整张卡片做成 `<section>` + JS 事件委托，不是 `<a>`/`<button>`、无 role、无 onclick 属性，前十条全部漏过；而它点击后只改自己某个元素的文字，让位检测的四个判据全部沉默——D9 的「行为即检测」在这个形态上失效。`cursor:pointer` 与 D10 删掉的 `zoom-in` 不同：没有方向歧义，只表示「点我」。只认「声明的边界」（父元素不再是 pointer 的那个），否则 `body{cursor:pointer}` 会整站失效。 | 给图片设 pointer 只为「点开看大图」的站点会被漏掉；`judge()` 多几次 `getComputedStyle`（实测仍 0.005 ms）。按第二条，漏图可接受，误接管不可接受。 | 这是对 D10「不需要静态规则」的直接反驳，依据是一次真实的让位盲区。若撤回本条，那个 H5 页面会立刻回到被接管的状态。 |
| D25 | **判断器第 11 条：原始尺寸是正方形且短边 < 600 px 的图，一律跳过。** | 二维码与头像都是正方形，且都过得掉面积（250×250 的二维码是 62 500 px²）与短边两道门槛；而用户点它们是想扫它、看这个人，不是想看这张图。这类误接管的代价是第二条里最贵的一种。 | 500×500 的正方形插画、正方形商品图会被一起跳过。按第二条，漏图可接受。 | 若撤回本条，登录页二维码与个人主页大头像会重新被接管（`docs/cases.md` 003）。 |
| D26 | **复制图片超过 canvas 像素预算时，改为复制地址，并把这次降级讲出来。** | `MAX_BYTES`（64 MB）管的是字节，不是像素：64 MB 的 JPEG 能解出 300 MP，画进 canvas 要 1.2 GB 的 RGBA，标签页会被 OOM 杀掉。而两种失败的代价不对称——「复制失败」是一次右键，「标签页崩」是一次卸载（第二条的代价表）。`toPng` 因此设两道闸：单边 16384（Chrome 的 canvas 上限）与总面积 32 MP；超了就 `copyText(url)`，并 toast 说明拿到的是地址。 | 超大图的「直接粘出图片」；这类图仍可保存（保存走原始字节，不经 canvas）。 | 撤回本条 → 一张 12000×9000 的图点复制会让标签页被杀。`npm run verify` 覆盖不到这条（需要真剪贴板），只能靠 manual-check 第 8 条。 |
| D27 | **shadow host 只声明 `role="dialog"`，不写 `aria-modal`，也不抢焦点。** | `aria-modal="true"` 的语义契约是「焦点已进入对话框、外部内容不可交互」，而实现刻意不 focus——第三条禁止抢焦点（页面能观测到 blur 的地方，视频会暂停、编辑器会失焦）。撒谎的 ARIA 比缺失的 ARIA 更糟：读屏用户会被告知身处模态对话框，而 Tab 键仍然走页面。 | 读屏用户的可发现性。要补就得「打开时 focus + 关闭时还原」，那会触发页面 blur 事件，先得推翻第三条。 | 打开一张图后焦点不移动是预期行为；若哪天实现了焦点管理，应当**撤回**本条，而不是让两条并存。 |
| D28 | **「页面接管了」记在那一层上，不记在站点上。** `acted()` 命中时把页面多出来的、盖住 90% 视口的那层记进 `Closer.state.shell`；后续点击只要这层还活着且 `contains(img)`，就继续让位。慢半拍的接管（迟到纠正）同样记。 | 用户报的 bad case（`cases.md` 006）：站点查看器开着时，第二次点击的四项判据全部沉默——增量检测看不见**已经发生**的接管。D9 的模型没错，它的结论只是原来只活一帧。把结论记到那一层上，等于给「页面接管了」这个事实一个寿命，而归因来自观测（它是在这次点击之后出现的），不是猜「这像不像查看器」，所以不需要任何尺寸/占比阈值——站点把图缩到 25%、放大后拖到一边，判据不受影响。**站点级自动黑名单被否决**：`acted()` 命中的原因远不止查看器（点卡片展开、tab 切换、SPA 软导航、慢挂广告），一次观测去赌整站行为，代价是不可解释、不可逆的整站失效，比「漏一张图」贵得多。 | 页面在**我们没看见的时刻**打开查看器时仍会叠一次：加载即开着、键盘/右键打开、点击后原地放大同一张图（`design §8`）。站点反复重建那一层时，重建后的第一次点击也会叠一次，点一次后重新记住。 | 若以后「没看见」这一类在真站点上变高频，补法是给 `shelled()` 加一个 OR 分支（静态存量判据），主结构不动；不要改成站点级标签。 |
| D29 | **两种语言：en（`default_locale`）+ zh_CN。用浏览器内置的 `_locales` + `chrome.i18n`，不引任何库、不加语言开关。** | 推翻 D8。D8 防的是「23 个语言包 = 五分之一体积、零个用户」，而这次的账不一样：39 条文案 × 2 种语言是 6.5 KB 的 JSON，**不进 content 预算**（宪法第六条只数 `src/content/*.js`），content 侧源码 46.2 → 47.7 KB 是因为多了 `Closer.t` 与调用点。检测也不用写：浏览器按 UI 语言挑 `_locales`，其余落回 `default_locale`——自己解析 `navigator.language` 只会得到一份更差的实现。不加开关是因为宪法第九条：能自动答对的问题不该抛给用户。 | 第三种语言；`zh_TW`（会落回英文）；商店文案的多语言仍要在开发者后台上传，manifest 里的 `__MSG__` 只影响 `chrome://extensions` 与权限弹窗。 | 撤回本条 → `tools/check-i18n.mjs` 立刻报 `_locales` 缺失、`verify` 退出码 1，界面回到全英文；而 D8 的前提「零个用户」已被证伪——是用户主动要的。 |

## 曾有分歧，已定案

| # | 问题 | 结论 | 一句话理由 |
| --- | --- | --- | --- |
| O1 | 判断器要不要看页面级上下文（视口占比、页内图片数量） | **不给** | 不可辩论、破坏单函数，且恰在页面不寻常处失效。 |
| O2 | 图集漫游 `←` `→` 进不进 v0.1 | **v0.2** | 整页排序是第二个决策面，同时上两个就无法归因。 |
| O3 | 「Pause here」够不够当逃生舱 | **够，并移入信息面板** | 可见但不必常驻；`Esc` 仍是主要出口。 |
| O4 | 无遥测下如何自我改进（本地标签集） | **暂缓** | 想法成立，但为一个还不存在的准确率问题引入表面积，顺序反了。 |
| O5 | overlay 打开时锁不锁滚动 | **不锁** | 打开期间消费 `wheel` 即可，避免布局跳动与 DOM 改动。 |
| O7 | 站点自带看图器时怎么不抢活 | **被动让位 + 库约定让路** | 行为即检测；静态规则只留零成本的明确声明。 |

O7 的推理过程保留在 git 历史里。要点：静态识别几乎不可能，因为「有没有查看器」是行为不是标记；而让它先动手、再验证它有没有消费这次点击，成本是 16 ms 和双开风险，收益是整个问题消失。

O1 的边界在 D28 之后更清楚了：**判断器仍然不看页面级上下文**（「这张图值不值得看」只由元素及其祖先链回答），而让位层本来就在看页面状态（有没有一层盖住屏幕、我们是不是还在这层里）。两者不冲突，因为它们是两个问题。若哪天有人想把 `shelled()` 塞进 `judge()`，那是把 O1 又违反一次。

顺带修正一处此前的错误：早期版本写的是「`cursor: zoom-in` → 强制打开」，方向是反的。现在这条规则已删除，而不是反转——因为它本来就该由行为回答。

## 已否决

| 方案 | 理由 |
| --- | --- |
| 右键菜单作为主入口 | 安全但摩擦大；那是「你记得要用」的工具，不是浏览器的一种行为。 |
| 在 manifest 里直接声明 `<all_urls>` | 在用户知道为什么之前索要最大权限，且撤销很难解释。 |
| Popover API / top layer | 关闭态的 UA `display: none` 与 `:host { display: block }` 冲突，收益不足以抵消复杂度。 |
| React / Vite / CRXJS | 为一个带 `transform` 的元素上渲染循环。违反第五、六条。 |
| 23 个语言包 | 五分之一体积，零个用户。（两种语言不算——见 D29） |
| 从暂停事件里自动调参 | 不可辩论的行为，违反第七条。 |
| 做配套网站「分析」图片 | 为浏览器本地就能做的事制造外发流量，违反第四条。 |
| 常驻尺寸 HUD | 主视图上多一行数字，换来的是每次都要看的一眼；收进面板更克制。 |

Closer — Privacy Policy

Last updated: 2026-10-26 · Version 0.1.0

Closer is a Chrome extension that opens the image you click at its real size. This page describes exactly what it does with data. It is short because the extension does very little: no account, no server, no analytics, no third-party code.

What Closer does not do

  • It does not collect, transmit, sell, or share any personal data. There is no backend of any kind.
  • It does not use analytics, telemetry, crash reporting, remote configuration, or feature flags.
  • It does not load remote code. Every line that runs ships inside the extension package and is readable in the source.
  • It does not read page text, form values, clipboard contents, browsing history, or cookies as data.
  • It does not track you across sites, and it stores nothing that identifies you.

What stays on your device

Two small settings are kept in the browser's local extension storage (chrome.storage.local) and never leave the machine:

  • the backdrop style you picked (dark, light, or checkerboard);
  • the list of sites you paused Closer on.

Removing the extension deletes both. There is no sync and no copy elsewhere.

The one network request

When you open an image, Closer asks the browser for the bytes of that image's own URL, so it can show the true file size and format — and, if you click save, hand you the original file. The request goes to the site that served the image, with the browser's normal credentials for that site; Closer adds no server of its own to the path, and no header that identifies you.

Those bytes are measured in memory and then discarded. Nothing is uploaded, nothing is written to disk unless you explicitly save the image. Opening an image that is already cached triggers no network request at all.

Permissions, and why each one is needed

  • storage — remembers the two settings listed above, locally.
  • scripting — injects the viewer into the page you are already looking at.
  • activeTab — when you click the toolbar icon, reads only the current tab's site name so the popup can say where you are.
  • Optional site access (all sites) — Closer works on any page, so it asks once, from a button you press, for permission to run on sites you visit. Until you press it, Closer does nothing at all. It can be revoked at any time from the welcome page, the popup, or chrome://extensions, and the viewer is unregistered immediately.

Closer — 隐私政策

最后更新：2026-10-26 · 版本 0.1.0

Closer 是一个 Chrome 扩展：点任意一张图，按它原本的尺寸看清它。这一页说明它到底怎么对待数据。篇幅短，是因为它做的事很少——没有账号、没有服务器、没有埋点、没有第三方代码。

Closer 不做什么

  • 不收集、不上传、不出售、不共享任何个人数据。它背后没有任何服务端。
  • 不使用统计分析、崩溃上报、远程配置或功能开关。
  • 不加载远程代码。跑起来的每一行都随扩展一起发布，源码可读。
  • 不读取页面正文、表单内容、剪贴板、浏览历史，也不把 Cookie 当作数据读取。
  • 不做跨站追踪，不存储任何能指向你个人的信息。

留在你设备上的东西

两项小设置保存在浏览器本地的扩展存储（chrome.storage.local）里，永远不会离开这台机器：

  • 你选择的背板样式（深色 / 浅色 / 棋盘）；
  • 你在哪些站点上暂停了 Closer。

卸载扩展即一并删除。没有云同步，也没有第二份拷贝。

唯一的一次网络请求

打开一张图时，Closer 会向 这张图自己的地址 取回字节，用来显示真实文件大小与格式；如果你点保存，则用它把原文件交给你。请求发往提供这张图的站点，携带的是浏览器对该站点的常规凭证；Closer 不会在这条链路上加入自己的服务器，也不加任何能标识你的头。

这些字节只在内存里被测量，随后丢弃。不上传、不写盘——除非你主动保存这张图。打开一张已被浏览器缓存的图，不会产生任何网络请求。

权限与用途

  • storage — 在本机记住上面那两项设置。
  • scripting — 把查看器注入你正在看的那个页面。
  • activeTab — 点工具栏图标时，只读当前标签页的站点名，让 popup 能告诉你现在在哪。
  • 可选的站点访问（所有站点） — Closer 要在任何页面上工作，所以它只在你按下那个按钮时、一次性申请在你访问的站点上运行的权限。在你按之前，它什么都不做。你可以随时在欢迎页、popup 或 chrome://extensions 里撤销，查看器会立即注销。

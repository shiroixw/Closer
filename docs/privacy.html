Privacy Policy

Last updated: 2026-10-26 · Version 0.1.0

Closer is a Chrome extension that opens the image you click at full size. It has no account, no server and no analytics, so this policy is short.

What Closer doesn't do

  • It doesn't collect, send, sell or share any personal data. There is no server.
  • It doesn't use analytics, telemetry, crash reporting or remote configuration.
  • It doesn't load code from the internet. Everything that runs is inside the extension, and the source is public.
  • It doesn't read page text, form fields, the clipboard, your browsing history or cookies.
  • It doesn't track you across websites.

What's stored on your device

Two settings, saved in the browser's extension storage (chrome.storage.local). They never leave your computer:

  • the backdrop you picked (dark, light or checkerboard);
  • the sites where you paused Closer.

Uninstalling Closer deletes both. Nothing is synced.

Network requests

When you open an image, Closer requests that image's own address to find out its file size and format. If you click save, the same data is used to save the original file.

The request goes to the website that hosts the image, the same way the page loaded it. Closer doesn't route it through any server and doesn't add anything that identifies you. The data is kept in memory and then thrown away; nothing is uploaded. If the browser already has the image cached, no request is made.

Permissions

  • storage: saves the two settings above on your device.
  • scripting: adds the image viewer to the page you're on.
  • activeTab: lets the toolbar popup show which site you're on.
  • Optional access to all sites: Closer only starts working after you allow this on its welcome page. You can turn it off any time from the welcome page, the toolbar popup or chrome://extensions, and it stops right away.

Contact

Questions or problems: github.com/shiroixw/Closer/issues.

隐私政策

最后更新：2026-10-26 · 版本 0.1.0

Closer 是一个 Chrome 扩展，点一下网页上的图片，就能按原尺寸查看。它没有账号、没有服务器，也不做数据统计，所以这份说明很短。

Closer 不会做的事

  • 不收集、不上传、不出售、不分享任何个人数据。它没有服务器。
  • 没有数据统计、遥测、崩溃上报，也不从网上拉取配置。
  • 不从网上加载代码。运行的代码都在扩展包里，源码公开。
  • 不读取网页正文、表单内容、剪贴板、浏览记录和 Cookie。
  • 不跨网站追踪你。

保存在你电脑上的东西

两项设置，存在浏览器的扩展存储（chrome.storage.local）里，不会离开你的电脑：

  • 你选的背景（深色、浅色或棋盘格）；
  • 你暂停了 Closer 的网站列表。

卸载 Closer 后，这两项会一起删除。不会同步到任何地方。

网络请求

打开一张图时，Closer 会请求这张图本身的地址，用来读出文件大小和格式。如果你点了保存，保存的就是这份原文件。

请求发往存放这张图的网站，和网页加载这张图的方式一样。Closer 不经过任何服务器，也不附加能识别你的信息。数据只在内存里用一下就丢掉，不会上传。如果浏览器已经缓存了这张图，就不会发请求。

权限说明

  • storage：在你电脑上保存上面那两项设置。
  • scripting：把查看器加到你正在看的网页里。
  • activeTab：让工具栏弹窗显示你当前所在的网站。
  • 可选的「访问所有网站」：只有你在欢迎页里点了允许，Closer 才开始工作。之后可以随时在欢迎页、工具栏弹窗或 chrome://extensions 里关掉，关掉立即生效。
